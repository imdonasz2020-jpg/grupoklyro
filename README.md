# Klyro: Elevate Your Brand

Crie uma landing page PREMIUM para a empresa GRUPO KLYRO, uma agência de marketing, tecnologia, performance e produção audiovisual especializada em ajudar empresas a vender mais, fortalecer sua marca e construir uma presença digital de alto nível.

A Klyro atende empresas de forma estratégica, combinando marketing, tecnologia, tráfego pago, gerenciamento de redes sociais, produção audiovisual, websites, softwares e automações.

Um diferencial importante da empresa é o atendimento presencial em todo o Vale do Paraíba, permitindo proximidade com os clientes e produção de conteúdo diretamente nas empresas.

A landing page deve transmitir imediatamente:

Exclusividade

Tecnologia

Performance

Sofisticação

Autoridade

Produção audiovisual profissional

Atendimento próximo

Presença regional

Resultado

NÃO quero aparência de agência de marketing genérica.

Quero uma estética semelhante à de uma empresa premium de tecnologia + performance + produção audiovisual cinematográfica.

HERO — PRIMEIRA IMPRESSÃO

O primeiro bloco deve ocupar praticamente toda a tela.

Utilizar como BACKGROUND um vídeo profissional produzido pela própria Klyro.

O vídeo deve:

ocupar 100% da área do hero

funcionar em autoplay

funcionar em loop

estar muted

utilizar object-fit: cover

possuir uma camada escura/gradient overlay para garantir legibilidade

ter carregamento otimizado

possuir poster/thumbnail enquanto o vídeo carrega

ter fallback visual caso o vídeo não carregue

Criar no código um local extremamente simples para substituir o vídeo posteriormente.

Exemplo:

VIDEO_URL = "/videos/klyro-hero.mp4"

Não utilizar vídeo stock aleatório.

O vídeo será fornecido pela Klyro.
